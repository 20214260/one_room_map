# 업데이트 적용과 시연

이 전달본은 기존 원본 ZIP을 확장한 전체 소스입니다. node_modules, 실제 환경변수, 빌드 결과, Git 이력은 포함하지 않습니다. package.json/pnpm-lock.yaml은 원본을 유지했습니다.

## 기존 VS Code 프로젝트에 적용

1. 실행 중인 터미널에서 Ctrl+C로 서버를 끕니다. `git status`로 현재 브랜치와 미커밋 작업을 확인하고 본인 변경사항은 먼저 보관하세요.
2. ZIP을 **별도 임시 폴더**에 풉니다. 그 안의 프로젝트 파일을 기존 `one_room_map`에 복사합니다. 기존 `.git`, `node_modules`, `.env.local`을 삭제하지 않습니다. 같은 이름의 변경 파일만 교체하세요. 다른 작업 중인 파일이 있다면 `docs/CHANGED_FILES.md`와 비교해 병합합니다.
3. 아래 명령을 기존 프로젝트 루트 터미널에서 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Windows에서 서버가 `read ECONNRESET`으로 종료되면 `pnpm exec vite --config vite.local.config.ts`를 실행하고 `http://127.0.0.1:5173`으로 접속합니다. 실제로 Windows 기기에서 발생한 연결 끊김에 대응해 프론트엔드 시연용 Node 로컬 실행 설정을 추가했습니다.

4. 터미널에 표시된 localhost 주소로 접속합니다. 기본 포트는 5173입니다. 이미 `.env.local`에서 DATA_MODE를 http로 설정했다면 시연할 때 `NEXT_PUBLIC_DATA_MODE=mock`으로 바꾸고 서버를 재시작하세요.

## 먼저 확인할 흐름

1. 로그인 화면에서 **집주인으로 체험** → 내 매물 관리 → 새 매물 등록.
2. 제목 `테스트 햇살 원룸`, 위치 설명 `순천대 정문 인근`, 월세 `32`(만원), 연락처 `010-0000-0000`을 입력합니다. 지도에서 위치를 선택합니다. 키 없는 mock에서는 정문 주변 선택 버튼을 써도 됩니다.
3. 다음 단계에서 사진 추가, 보증금 `300`, 관리비 `0`, 옵션 선택. **설명 초안**을 만들고 검토 후 적용합니다. 내용을 직접 수정할 수 있는지 확인합니다.
4. 마지막 단계에서 확인 체크 후 등록합니다. 내 매물 목록에서 수정·비공개·재공개·거래 완료도 확인합니다.
5. 매물을 공개 상태로 둔 뒤 로그아웃합니다. **같은 탭**에서 로그인 → **사용자로 체험**.
6. 방 찾기에서 필터를 초기화하고 등록한 제목으로 검색합니다. 지도 핀·사진·상세·비교에 반영되는지 확인합니다. 직접 등록 매물 상세에서 예시 연락처로 문의를 남깁니다.
7. 로그아웃 → **집주인으로 체험** → 받은 문의에서 메시지와 읽음 처리를 확인합니다.
8. 사용자 계정으로 `/landlord/new`에 접근하면 집주인 안내가 나오는지 확인합니다. 휴대폰 너비와 데스크톱 너비에서 버튼·사진·입력 영역을 확인합니다.

체험 계정과 임시 회원가입 계정은 다른 계정입니다. 시연 중에는 두 체험 버튼으로 전환하세요. 탭을 닫으면 데이터 유지가 보장되지 않습니다. 실제 연락처·비밀번호·실매물은 넣지 마세요. 현재 문의는 시연 저장이며 문자나 카카오 메시지가 실제로 가지 않습니다.

## 팀원에게 전달

`docs/LANDLORD_HANDOFF.md`와 `docs/openapi.json`을 먼저 공유하세요. AI 담당자는 `/rooms/draft` 계약, BE 담당자는 role/owner 권한 및 `/owner/*` 계약을 보면 됩니다. HTTP 실인증·저장·업로드·AI는 후속 연동 대상입니다.

권장 커밋 메시지: `feat: 역할별 가입과 집주인 매물 등록·관리 프론트 추가`

이번 전달 과정에서 원격 저장소 커밋·push·main 병합·배포는 하지 않았습니다.
