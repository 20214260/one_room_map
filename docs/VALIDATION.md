- 자연어 입력 후 규칙 기반 요약·한계 표시 확인.

## 전달 시 배포 상태

최종 로컬 빌드는 성공했습니다. Sites 연동이 `Invalid MCP request metadata` (HTTP 400)를 반환하여 원격 소스 동기화와 비공개 웹 배포는 완료하지 못했습니다. 미배포 상태를 실제 서비스 URL로 안내하지 않습니다.
